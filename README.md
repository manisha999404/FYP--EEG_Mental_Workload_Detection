# EEG Mental Workload Detection

## Overview

This project focuses on detecting human mental workload from EEG signals using Digital Signal Processing (DSP), Machine Learning, and Deep Learning techniques.

The project uses the **STEW (Simultaneous Task EEG Workload)** dataset.

## Project Pipeline

Raw EEG Data
→ Preprocessing
→ Feature Extraction
→ Machine Learning
→ Deep Learning (EEGNet)
→ Mental Workload Prediction
